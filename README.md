# Tetris (Raylib + C++)
A simple Tetris game project made with raylib library in c++, offers a pretty generic Tetris gameplay experience, a simple UI, as well as music and sound.

## Requirements
- CMake (3.15+)
- A C++17 compiler

## Build & Run
git clone https://github.com/Zakaria-Mamouri/Tetris-with-Raylib.git
cd Tetris-with-Raylib
cmake -B build
cmake --build build
